## Highlighted work

### Crunchy Neck — Autonomous AI Agent
**Mar 2026** · [GitHub](https://github.com/shing1Sks/Crunchy-Neck)

A Python agent I reimplemented from scratch, inspired by multi-layer ReAct designs (not a wrapper around someone else's stack).

Runs on GPT-5.2 and Kimi K2 (Groq). 13 custom tools — shell, background processes, files, ChromaDB memory, web search, TTS, image gen. A computer-use subagent ("Scout") for browser/desktop. Terminal + Telegram as interfaces. Two-level prompt compaction, session wrapup, and a PERSONALITY / USER / MEMORY identity layer so context survives across sessions.

This is the project that best represents how I think about agents: tools, memory, identity, and control loops as one system.

### EmoGPT — LLM Token Efficiency Research
**Sep – Oct 2025** · [GitHub](https://github.com/shing1Sks/emoGPT)

Can emoji-based context encoding cut tokens, latency, and API cost without killing expressiveness?

Built the conversion/parsing/token-analysis pipeline, compared emoji-encoded vs plain-text usage, and fine-tuned with LoRA so models could read and write the encoding. Early gains on targeted tasks; published the experiment trail on GitHub and LinkedIn.

Research-shaped work with a practical production question underneath: cheaper context without dumber models.

### AI Assignment Automation
**Mar 2026** · n8n + OSS models · [GitHub](https://github.com/shing1Sks/IdoAssignments) *(private — LinkedIn walkthrough)*

Fully autonomous classroom → solution → submit pipeline. Multi-step n8n nodes, OSS LLMs for extraction/generation/formatting, branching and error handling for messy edtech formats.

Proof that agentic automation doesn't need a huge custom stack — orchestration + good models can replace a repetitive cognitive workflow end-to-end.
